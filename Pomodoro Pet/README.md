# Pomodoro Pet

A cozy Pomodoro timer that rewards completed focus sessions with XP and coins for a virtual pet.

[GitHub](https://github.com/PsReader/PomodoroPet)

## Features

- focus, short-break, and long-break timers with timestamp-based accuracy
- XP, coins, streaks, and daily session tracking
- a virtual pet that evolves through three stages — Tiny Sprout, Focus Bloom, and Study Sage
- cosmetic accessory shop with coin purchases
- focus garden and achievement collection
- sound and reduced-motion preferences
- all progress stored locally in the browser, with reset and save backup controls

## How to run

No build step, account, or backend required. Open `index.html` directly in a browser.

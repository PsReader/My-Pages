MEMORY OF THE TAROT CLUB

Upload these files together to your web host:
- index.html
- style.css
- game.js

No build step, npm, React, database, or server is required.
Open index.html through your host's web address.

Each difficulty is a run of levels — Small Rite has 5, Medium 7, Large 10.
Clearing a level advances the run; running out of time resets to level 1.
Progress is saved in the visitor's browser (localStorage keys with the
"tm." prefix): stars, every cleared level (RITES SEALED counter), and the
number of completed runs per difficulty shown under each Difficulty button.

Three themes (Classic Sepia / Violet Dusk / Rosewood Ritual), a Pattern
Safe mode for non-color cues, and a gallery of all 22 Major Arcana sigils
from TarotDraw.

# Witbit refresh — approved outcomes

- [x] **Distinctive authored landing page:** Redesign the supplied Witbit landing page so the first impression feels less basic, more memorable, and intentionally human rather than like a generic AI template.
- [x] **Stronger opening composition:** Introduce Witbit as “a book of little beginnings” with rhythmic copy, an asymmetric editorial hero, a field-note card, and a clear invitation into the idea cabinet.
- [x] **Handmade editorial visual system:** Use tactile paper texture, red-pencil marks, ink-stamp details, marginalia, rules, labels, deliberately imperfect rotation, and a warmer authored voice without adding decorative imagery that has no editorial role.
- [x] **Preserved idea generator functionality:** Keep the four existing generators for tiny quests, names, story sparks, and team names, including their existing controls, generation logic, copy action, and another-idea action.
- [x] **Varied generator discovery layout:** Give each generator category a clear place in a cabinet/index composition while retaining the existing accessible tab and panel relationships.
- [x] **Purposeful interaction states:** Keep active, hover, focus, loading, and generated-result states consistent, with small tactile transitions that do not feel slick or mechanical.
- [x] **Responsive recomposition:** Recompose the hero, field note, cabinet, result card, method section, and footer for tablet and mobile widths instead of only shrinking the desktop layout.
- [x] **Accessible semantic structure:** Retain semantic landmarks, labels, live status messaging, keyboard-operable tabs, readable contrast, and visible focus states.
- [x] **Specific naming traditions:** Expand the name generator beyond broad mood labels with explicit Japanese, Chinese, Korean, Latin, Greek, German, French, Italian, and Spanish name sets, while keeping the original whimsical, mysterious, cozy, and grandiose choices.
- [x] **Coherent game/project titles:** Add a dedicated “game or project” target with tradition-specific title banks, and prevent regional selections from being wrapped in unrelated English patterns such as “The … Parade,” “III,” or “of Nowhere.”
- [x] **Richer tiny quests:** Expand quest types, locations, moods, and task sentences, and add a companion choice that is carried through into the generated quest instead of being selected but ignored.
- [x] **Richer team names:** Expand team themes to include weather, folklore, and workshop worlds; add cozy, rebellious, scholarly, and dramatic personalities; and vary the final naming structure instead of always concatenating two words.
- [x] **Lore and backstory generator:** Add a fifth cabinet drawer that combines subject, regional tradition, setting, hidden truth, and tone into a compact multi-sentence backstory.
- [x] **Regional item and loot generator:** Add a sixth drawer with Japanese, Chinese, Korean, Latin, Greek, German, French, Italian, Spanish, and folkloric item banks, plus item type, material, power, and origin-detail choices.
- [x] **Project structure preserved:** Keep the supplied static site structure and route manifest; no framework migration or unnecessary infrastructure was introduced.

- [x] **Regional encounter and trap generator:** Add a seventh drawer that creates encounters, traps, omens, and bargains across the existing regional themes.
- [x] **Name meanings:** Add a plain-language meaning/gloss to every generated name result, including regional names and title banks.

- [x] **Drawer sound cues:** Add opt-in Web Audio cues for each cabinet drawer, with regional timbre variation and no external runtime asset dependency.
- [x] **Historical name context:** Add researched etymology, cultural background, and source links to regional name results.

- [x] **Encounter drawer personality pass:** Add live regional field notes, regional scene profiles, drawer-specific status voice, and reactive color styling.

- [x] **Drawer particles and trap motion:** Add custom particle bursts when opening drawers plus a reduced-motion-safe shake and warning burst for trap results.
- [x] **Mobile companion layout:** Recompose the cabinet into a one-column touch-friendly flow with sticky access, larger controls, mobile action rows, and long-note handling.
- [x] **Cabinet density fix:** Remove the translucent book-spine overlay and compact the seven-drawer desktop index into a balanced two-column layout while preserving the mobile list.
- [x] **Search and AI-readable discovery:** Keep meaningful generator descriptions in the initial HTML, add a focused page title and description, align social titles and descriptions, include accurate WebApplication structured data, and provide a plain-text llms.txt overview without treating generated output as factual authority.
- [x] **SVG favicon and matching install color:** Provide a self-contained, scalable SVG favicon and align the web-manifest theme color with the page's browser theme color.
- [x] **Cabinet desktop and tablet layout:** Keep all seven desktop drawer labels readable in a single-column sidebar, move the two-column index above the writing desk on tablet widths, keep result actions on one row at desktop width, and preserve the mobile single-column flow without horizontal overflow.

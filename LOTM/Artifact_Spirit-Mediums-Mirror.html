Spirit Medium's Mirror

Grade 3 · Code 3-0217

Overview

Spirit Medium's Mirror (3-0217) is recorded in the archive as a Grade 3 Sealed Artifact. Grade 3 artifacts are the lowest sealed class, roughly Sequence 8 to Sequence 9.

It is described as: A mirror, its back is plated in mercury, the front has three minor cracks.

Function

Whoever looks into it encounters danger.

Downside

Affects the user as well.

Status

No status is recorded in the source table.

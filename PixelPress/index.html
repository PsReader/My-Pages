    Good to know

    Are my images uploaded?

    No. The file is decoded and processed in your browser. Pixelpress does not use an upload endpoint.

    When should I use WebP?

    WebP is a strong default for web images because it usually delivers a smaller file than JPG or PNG at a similar visual quality.

    What happens to transparent pixels in JPG?

    JPG cannot store transparency. Pixelpress composites transparent areas over the background color you choose.

    Pixelpress is a browser-only image compressor and converter. No upload required.

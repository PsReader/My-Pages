Lumen / color formats

Color input reference

Use the color notation your workflow already speaks.

Lumen converts common CSS color formats locally, while keeping the last valid result visible if an input is temporarily incomplete or invalid.

Try the color inputs

Supported formats

HEX

Use 3-digit or 6-digit values, with or without #.

#767676
fff

RGB

Use integer channel values from 0 to 255.

rgb(118, 118, 118)

HSL

Use hue, saturation, and lightness values.

hsl(0 0% 46%)

OKLCH for perceptual work

OKLCH separates lightness, chroma, and hue in a way that is useful when exploring perceptual adjustments. Lumen converts it to sRGB for the WCAG luminance calculation, then keeps the displayed value in your selected format.

oklch(55% 0.02 180)

All calculations stay in your browser. Return to Lumen.

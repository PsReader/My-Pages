Lumen / palette contrast matrix

Color system workflow

Compare a palette before it ships.

Design systems rarely have one color pair. The palette matrix checks multiple text and background colors together so weak combinations are visible early.

Open the palette matrix

What to compare

Text roles

Test body copy, labels, captions, links, and muted text colors against every intended surface.

Background roles

Compare page backgrounds, cards, fields, navigation bars, and dark mode surfaces.

AA and AAA

Each matrix cell reports both normal-text AA and enhanced AAA status, not just a single pass/fail.

How to use the matrix

  • Enter up to eight text colors and eight background colors.
  • Separate values with commas, spaces, or new lines.
  • Use the result to decide which semantic roles need a different color.
  • Open a promising pair in the main checker for live component previews and adjustment suggestions.

Use the Lumen palette matrix for batch checks, then validate the final pair in context.
